# JaNea Muldowney website

Preview of the Alchemy Scalp Wellness website for JaNea Muldowney, certified clinical trichologist in Oceanside, CA.

A plain static site: open `index.html` in a browser, or publish the folder with GitHub Pages (Settings > Pages > Deploy from branch > `main` / root).

| Page | File |
| --- | --- |
| Homepage | `index.html` |
| Product pages | `dht-inhibitors.html`, `growth-factors.html`, `hair-complex.html`, `herbal-conditioner.html`, `herbal-shampoo.html`, `scalp-prep.html` |

This is a design preview. Prices are placeholders, the booking form shows a thank-you message but does not send anything yet, and Add to cart only updates the counter. The live store is built from the Shopify theme sections.
